# DC101_Game_GardiolaJhonBenedict
DC10_GAME_PROJECT
Shape Dodger 

A fast-paced HTML5 Canvas game where you dodge falling shapes and survive as long as possible.

Features
- Semantic HTML
- Responsive CSS
- Vanilla JavaScript
- LocalStorage leaderboard
- Difficulty levels
- Power-ups

How to Run
1. Clone the repo
2. Open `index.html` in your browser
3. Play.

Controls
- Move mouse left/right to dodge shapes

Tech Stack
- HTML5
- CSS3
- JavaScript (ES6)
